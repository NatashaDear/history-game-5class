# history-game-5class
Игра по учебнику истории 5 класс, авторы Мединский, Чубарьян 2026 год

🧩 Как добавить новую главу
Откройте этот файл в любом редакторе.

Найдите в коде объект historyDatabase.

Вставьте новый блок, например:

javascript
chapter3: {
    title: "Глава 3. Первые государства",
    desc: "Описание главы...",
    schoolDirect: [ ... ],
    schoolReverse: [ ... ],
    schoolOge: [ ... ],
    olympiad: [ ... ]
}
Сохраните файл и загрузите на GitHub – кнопка для новой главы появится автоматически.
